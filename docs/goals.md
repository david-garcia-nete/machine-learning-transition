# Goals

## Primary Goal

Develop enough practical ML engineering capability to design, build, evaluate, and explain machine learning systems with the judgment expected from an experienced software engineer entering ML specialization.

## 12-Week Goals

- [ ] Refresh ML-relevant calculus, linear algebra, probability, and statistics.
- [ ] Build intuition for classical ML models, baselines, metrics, and validation.
- [ ] Become comfortable writing and modifying PyTorch training workflows.
- [ ] Understand transformer and LLM foundations well enough to reason about architecture and limitations.
- [ ] Define credible portfolio project plans with evaluation strategies.
- [ ] Document progress clearly enough that the repo communicates learning discipline.

## Portfolio Goals

- [ ] Select one primary portfolio project for deeper implementation.
- [ ] Define the problem, user, constraints, and evaluation plan for each candidate project.
- [ ] Avoid assuming datasets exist; document data discovery and acquisition options.
- [ ] For each project, identify a simple baseline before advanced modeling.
- [ ] Record risks, unknowns, and next actions.

## Professional Goals

- [ ] Translate backend and cloud experience into ML systems vocabulary.
- [ ] Practice explaining model choices, tradeoffs, and failure modes.
- [ ] Build artifacts suitable for technical conversations and interviews.
- [ ] Develop a repeatable learning cadence that can continue after the first sprint.
