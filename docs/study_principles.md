# Study Principles

## Core Principles

1. **Active recall over passive reading.** Write explanations, solve problems, and teach concepts back in your own words.
2. **Implementation follows intuition.** Understand the idea, then implement enough to expose gaps.
3. **Baselines first.** A simple baseline gives context for every advanced model.
4. **Evaluation is part of the product.** Metrics, validation strategy, and failure analysis are not optional.
5. **Small weekly deliverables.** Prefer consistent progress over large unfocused study blocks.

## Weekly Learning Loop

- [ ] Choose one primary topic.
- [ ] Define two or three concrete outcomes.
- [ ] Complete focused study notes.
- [ ] Create or update an exercise, project plan, or evaluation artifact.
- [ ] Record blockers and open questions.
- [ ] Update progress tracking.

## Definition of Done for a Topic

A topic is not done when it has been read. It is done when you can:

- [ ] Explain the concept without notes.
- [ ] Identify when it applies and when it does not.
- [ ] Connect it to at least one ML workflow or project.
- [ ] Name common failure modes or misconceptions.
- [ ] Use it in a small exercise, model, design, or written decision.
