# Machine Learning Transition

## Purpose

This repository documents a focused transition from experienced software engineer to machine learning engineer. It is intended to be both a learning system and a portfolio workspace: a place to plan, study, build, evaluate progress, and turn technical growth into visible project outcomes.

The goal is not to relearn software engineering from scratch. The goal is to add the mathematical, statistical, modeling, deep learning, PyTorch, transformer, and MLOps skills needed to operate credibly in practical machine learning engineering roles.

## Background

Starting strengths:

- M.S. in Computer Science
- 10+ years of professional software engineering experience
- Backend development and API design
- SQL, databases, and production data handling
- Cloud, deployment, and operational experience
- Current refresh of calculus, linear algebra, probability, and statistics

Target specialization areas:

- Practical machine learning
- Deep learning and PyTorch
- Transformers and LLM foundations
- MLOps, evaluation, deployment, and monitoring
- Portfolio projects that demonstrate engineering depth and ML judgment

## Learning Philosophy

This repo follows a serious, practical, project-centered learning approach:

- **Refresh math with purpose.** Focus on concepts that directly support optimization, probability, modeling, and deep learning.
- **Build while studying.** Every concept should eventually connect to an experiment, notebook, system design, or project decision.
- **Treat ML as engineering plus evidence.** Code quality matters, but so do evaluation, baselines, data assumptions, failure analysis, and reproducibility.
- **Favor durable foundations over tool chasing.** PyTorch, transformers, and MLOps tools are important, but the goal is transferable judgment.
- **Use prior engineering experience as leverage.** Backend, APIs, data systems, and deployment experience should become an advantage in ML engineering work.

## 12-Week Sprint Summary

| Weeks | Focus | Outcome |
| --- | --- | --- |
| 1-3 | Math refresh | Rebuild fluency in calculus, linear algebra, probability, and statistics for ML. |
| 4-5 | Classical ML | Implement and evaluate core supervised and unsupervised learning workflows. |
| 6-8 | PyTorch and deep learning | Build practical neural network training loops and understand deep learning fundamentals. |
| 9-10 | Transformers and LLM foundations | Study attention, transformer architecture, tokenization, embeddings, and LLM usage patterns. |
| 11-12 | ML engineering and deployment concepts | Connect models to production concerns: data pipelines, serving, monitoring, evaluation, and iteration. |

See [`roadmap/12_week_sprint.md`](roadmap/12_week_sprint.md) for the detailed sprint plan.

## Portfolio Project List

1. **Inventory Forecasting** — forecasting demand or inventory needs using time-series and tabular modeling techniques.
2. **Music OCR / Sheet Music to MusicXML** — exploring computer vision and structured output for sheet music recognition.
3. **Opportunity Notebook AI** — an applied AI assistant for organizing opportunities, notes, decisions, and follow-ups.
4. **Recommendation System** — building and evaluating recommendation approaches from simple baselines to more advanced methods.

Each project starts with a README that defines purpose, possible milestones, assumptions, risks, and next actions. No datasets are assumed to already exist.

## How to Use This Repo

Recommended weekly workflow:

1. Review the current roadmap phase.
2. Choose a small number of measurable weekly outcomes.
3. Study the required foundation material.
4. Convert learning into exercises, experiments, or project artifacts.
5. Record notes using the journal template.
6. Update the progress dashboard and self-assessment.
7. End each week with a written review and next actions.
