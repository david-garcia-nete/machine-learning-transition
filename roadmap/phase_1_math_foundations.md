# Phase 1: Math Foundations

## Purpose

Refresh the math required to reason about machine learning rather than memorizing formulas. The goal is practical fluency: enough understanding to debug models, interpret optimization behavior, and read ML material with confidence.

## Topics

- Calculus: derivatives, partial derivatives, gradients, chain rule
- Linear algebra: vectors, matrices, dot products, matrix multiplication, norms, projections
- Probability: random variables, distributions, expectation, variance, conditional probability
- Statistics: estimation, sampling, confidence, hypothesis testing, bias and variance

## Milestones

- [ ] Explain gradient descent geometrically and algebraically.
- [ ] Connect matrix operations to batches, features, and neural network layers.
- [ ] Explain common distributions used in ML examples.
- [ ] Distinguish statistical noise from model error.
