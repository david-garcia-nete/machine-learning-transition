# Phase 5: Portfolio Projects

## Purpose

Convert learning into credible artifacts. Portfolio projects should demonstrate problem framing, data reasoning, modeling, evaluation, engineering design, and communication.

## Project Candidates

1. Inventory Forecasting
2. Music OCR / Sheet Music to MusicXML
3. Opportunity Notebook AI
4. Recommendation System

## Project Quality Bar

Each project should eventually include:

- [ ] Problem statement and target user
- [ ] Data assumptions and acquisition plan
- [ ] Baseline approach
- [ ] Evaluation strategy
- [ ] Modeling roadmap
- [ ] System design notes
- [ ] Risks and limitations
- [ ] Next actions

## Next Actions

- [ ] Choose one primary project for the first implementation sprint.
- [ ] Keep the other projects as scoped candidates, not distractions.
- [ ] Use weekly reviews to decide whether the primary project remains the best choice.
