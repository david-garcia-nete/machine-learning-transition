# 12-Week Machine Learning Transition Sprint

## Sprint Objective

Use twelve focused weeks to move from refreshed foundations to practical ML engineering readiness. The sprint emphasizes math, classical ML, PyTorch, deep learning, transformers, and deployment concepts, while continuously connecting study to portfolio projects.

## Weekly Plan

### Weeks 1-3: Math Refresh

**Focus:** calculus, linear algebra, probability, and statistics for ML.

Milestones:

- [ ] Review derivatives, gradients, chain rule, and optimization intuition.
- [ ] Review vectors, matrices, dot products, matrix multiplication, norms, eigenvectors, and dimensionality.
- [ ] Review probability distributions, expectation, variance, Bayes' rule, sampling, and statistical inference.
- [ ] Connect math concepts to loss functions, gradient descent, regression, classification, and neural networks.

### Weeks 4-5: Classical ML

**Focus:** model baselines, supervised learning, unsupervised learning, validation, and metrics.

Milestones:

- [ ] Study train/validation/test splits, cross-validation, leakage, and overfitting.
- [ ] Review linear regression, logistic regression, decision trees, random forests, gradient boosting, clustering, and dimensionality reduction.
- [ ] Practice metric selection for regression, classification, ranking, and forecasting.
- [ ] Define baseline strategies for portfolio projects.

### Weeks 6-8: PyTorch and Deep Learning

**Focus:** neural network fundamentals and PyTorch fluency.

Milestones:

- [ ] Understand tensors, autograd, modules, optimizers, and data loaders.
- [ ] Build mental models for training loops, loss functions, backpropagation, and regularization.
- [ ] Study embeddings, convolutional networks, sequence models, and common debugging patterns.
- [ ] Document a reusable deep learning experiment checklist.

### Weeks 9-10: Transformers and LLM Foundations

**Focus:** attention, transformer architecture, tokenization, embeddings, and LLM application patterns.

Milestones:

- [ ] Explain self-attention, positional encoding, feed-forward blocks, and residual connections.
- [ ] Understand tokenization and embedding tradeoffs.
- [ ] Study pretraining, fine-tuning, retrieval augmentation, prompting, and evaluation.
- [ ] Identify where transformer-based approaches may apply to portfolio projects.

### Weeks 11-12: ML Engineering and Deployment Concepts

**Focus:** turning models into reliable systems.

Milestones:

- [ ] Study experiment tracking, data versioning, reproducibility, and model registries.
- [ ] Review batch inference, online inference, monitoring, drift, and feedback loops.
- [ ] Map existing backend/cloud skills to ML deployment architecture.
- [ ] Create a deployment and monitoring plan for one portfolio project.

## Sprint Completion Criteria

- [ ] All weekly reviews completed.
- [ ] Progress dashboard updated each week.
- [ ] At least one project selected for deeper implementation.
- [ ] Each project README has a clear problem definition and next actions.
- [ ] A self-assessment identifies the next sprint focus.
