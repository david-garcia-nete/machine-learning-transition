# Phase 2: Classical Machine Learning

## Purpose

Build practical understanding of classical ML workflows before moving deeply into neural networks. Classical ML provides essential baselines and teaches evaluation discipline.

## Topics

- Regression and classification
- Feature engineering and preprocessing
- Model validation and cross-validation
- Metrics for different problem types
- Tree-based models and ensembles
- Clustering and dimensionality reduction
