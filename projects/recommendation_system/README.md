# Recommendation System

## Purpose

Build a recommendation system project that demonstrates ranking, evaluation, user-item modeling, and practical system design. This project can start with simple baselines and later expand into embeddings or neural recommenders.

## Problem Framing

Potential question: given users, items, interactions, and context, can a system recommend relevant items and explain the tradeoffs behind those recommendations?

No dataset is assumed. Dataset selection or synthetic data design must be documented.

## Possible Approaches

- Popularity baseline
- Recent activity baseline
- Content-based recommendations
- Collaborative filtering
- Matrix factorization
- Embedding-based retrieval or ranking models

## Evaluation Ideas

- Precision at K
- Recall at K
- Mean average precision
- Normalized discounted cumulative gain
- Coverage, novelty, diversity, and cold-start behavior
