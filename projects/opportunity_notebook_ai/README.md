# Opportunity Notebook AI

## Purpose

Build an AI-assisted notebook for tracking opportunities, notes, decisions, follow-ups, and context. This project connects backend engineering, product thinking, information retrieval, LLM application patterns, and evaluation of assistant behavior.

## Problem Framing

Potential question: can an assistant help organize unstructured opportunity notes into actionable summaries, reminders, tags, and next steps while preserving user control and traceability?

No dataset is assumed. Initial data may be manually authored, synthetic, or collected from personal workflows with privacy safeguards.

## Possible Approaches

- Rule-based tagging and structured templates as a baseline
- Embedding-based search over notes
- Retrieval-augmented generation for summaries and Q&A
- LLM-assisted extraction of tasks, dates, entities, and decisions
- Human-in-the-loop review for correctness

## Evaluation Ideas

- Retrieval relevance on curated queries
- Summary faithfulness and usefulness
- Task extraction precision and recall
- User review acceptance rate
- Latency and cost considerations
